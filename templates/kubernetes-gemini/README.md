# Kubernetes (Gemini) ❤️

Advanced development workspace supercharged with Google Gemini AI. Built with love for you.

## Features

- **Gemini CLI**: Built-in AI assistant for coding, explaining, and refactoring directly from the terminal.
- **Git Integration**: complete Git configuration and signing support.
- **Full Toolkit**: Includes all standard tools plus AI capabilities.

## Getting Started with Gemini

Once your workspace is running, you can use the `gemini` command in the terminal.

- **API Key**: The API key is automatically configured via `gemini_api_key` parameter.
- **Base URL**: Supports custom endpoints via `gemini_base_url`.

## Prerequisites

- **Cluster**: Kubernetes cluster required.
- **API Key**: A valid Gemini API key (or compatible proxy) is needed when creating the workspace.
